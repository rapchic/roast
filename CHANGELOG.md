All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-03

### Added

- Initial release: `roast` CLI with `init`, `install`, `update`, `status`, `uninstall`
- `roast context` — stack detection (Node, Python, Go, Rust, Java), scripts, conventions, CI
- `roast diff` — merge-base diff signals, area categorization, suggested scope
- Multi-IDE installer: Cursor, Claude Code, Codex
- Evidence-based roast skill with 6 modes
- Slash command rules for Cursor (`/roast`, `/roast-only`, `/roast-idea`, `/roast-ui`, `/roast-api`)
